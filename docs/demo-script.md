# 3–5 minute demo script

1. Open `/`. Explain that published research is public; accounts are required only for participation and private workflows.
2. Search **Artificial Intelligence**. Show grouped Research Areas, Researchers, Projects and Published Publications, then open one connected detail page.
3. Open an indexed publication and choose **Analyze this paper**. Ask a supported question, then an absent-fact question to show the grounded fallback. Show related research and compare two indexed papers.
4. Sign in as a demo student. Open `/account`, request researcher access, then show the pending state. As a demo admin, approve it from `/admin/access`.
5. With a demo researcher account, upload one completed DOCX or text-based PDF. Review the extracted fields, run Submission Readiness and submit. Explain that PDFs are best-effort, scanned PDFs have no OCR, references are checked structurally, and private files are not sent to Qwen.
6. As admin, open the submission queue, start review and publish or request changes. Return to the public publication directory after publishing.
7. Close with limits: all fictional institutional records say `DEMO DATA`; preflight is deterministic lexical guidance, not plagiarism or citation validation; Qwen uses an intentionally indexed public corpus and current demo transport still needs HTTPS/private networking for production.
