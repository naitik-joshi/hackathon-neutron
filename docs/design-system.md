# Design system

The hub is a research index with a clear route from ideas to participation. Use deep ink #142c43, paper #f5f7fb, white #ffffff, research blue #215ac7, muted slate #52677b and a restrained amber demo marker. Georgia display headings pair with system sans-serif body and monospace utility labels; no remote font dependency. A four-stage journey strip on the homepage makes Discover → Understand → Connect → Participate visible.

Use shared Button, Card, Badge, Input, Textarea, Select, PageHeader, EmptyState, StatusBadge and loading/error feedback. Native controls keep keyboard behavior predictable; shadcn-style composable primitives avoid unnecessary dependencies. Entity cards show type, title, summary and next link. No dead ends: empty states give a relevant next action. Status text never relies on color alone. All fictional records show DEMO DATA.

Responsive by default: single-column forms, wrapping navigation, readable line lengths, cards that collapse to one column. Visible focus, explicit labels, descriptive headings and live feedback after actions. Prefer pages to modal-heavy flows. Shared CSS/tokens require coordination. Keep styling restrained during bootstrap.
