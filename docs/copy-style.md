# Product copy style

- Use short, plain, academic language. State what the page or action does.
- Use sentence case for headings, labels and buttons: “Submit publication”, not title case.
- Name workflow states exactly: Draft, Submitted, Under review, Changes requested, Published, Rejected.
- Mark every fictional person, project, area and publication visibly as `DEMO DATA`.
- Errors say what failed and the next safe action without exposing infrastructure details.
- Prefer “Browse published research” and “Request researcher access” over promotional claims.
- Do not claim peer review, plagiarism detection, citation correctness, formal acceptance, funding, partnerships or guaranteed confidentiality unless the product proves it.
